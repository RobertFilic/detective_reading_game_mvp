# Detektivska pisarna – MVP validation prototype

A Slovenian detective reading game for children aged 6–9. The child accuses a suspect by tapping the sentence that proves it. The prototype exists to answer four playtest questions; see [docs/PLAN.md](../docs/PLAN.md) for the full plan, playtest protocol and thresholds.

## Files
| Path | What it is |
|---|---|
| `index.html` | The whole app: cases, screens, logging, adult debrief. No dependencies. |
| `audio/` | One recording per line, named `<clipId>.m4a` (empty until recorded). |
| `tools/cases.mjs` | Checks the cases against the template rules; `clips` lists every line to record. |
| `tools/build.mjs` | Inlines `audio/` into `dist/index.html` and copies `sw.js`. |
| `tools/shots.mjs` | Screenshots of every screen of a case on iPhone SE, iPad and a landscape phone, and flags overflow or an off-screen main button: `node tools/shots.mjs b6` (once: `cd tools && npm install`; needs Google Chrome). |
| `sw.js` | Offline cache for the hosted version. |

## Run locally
Open `solo/index.html` in a browser (or the start page `index.html` one level up). Run the `node tools/…` commands below from this `solo/` folder. The adult setup screen comes first. Without recordings, the app tries `audio/<clipId>.m4a` and then a Slovenian system voice (Edge on Windows has one; iPad Safari does not).

## Edit cases
Cases live in `index.html` between `// CASES-BEGIN` and `// CASES-END`. After editing, run:

```
node tools/cases.mjs
```

Every case has a `type`, a step on the reasoning ladder, and its difficulty (🔍 count on the board) follows from it:

| 🔍 | `type` | The child… |
|---|---|---|
| 1 | `fact` | finds the sentence that says it |
| 2 | `trace` | links a trace to a person (a blue tongue → blueberries) |
| 3 | `slip` | notices the culprit knows something only the culprit could know |
| 4 | `alibi` | finds the sentence that shows the culprit's claim isn't true |
| 5 | `pair` | picks **two** sentences that only prove it together ("Izberi dva stavka") |

`twist: true` marks a case where an animal of the place did it (a mouse, a goat); at most one per adventure.

The checker tests, per case: word limits, sentence, suspect and decoy counts, the evidence count for the type (2 for a pair), that slip and alibi cases have the culprit's own claim (`partial`), and hint references. Solvability: every suspect appears in the story; the evidence names the culprit and no other suspect; in a pair one proof names the culprit and the other names no suspect. Per adventure, it checks the ladder (starts with a fact case, rungs never go down, ends with a final two-proof case) and **variety**, so a child can't learn a pattern instead of reading: the proof sits early, in the middle and late across the adventure; no two cases have the same shape; the decoy sits straight before the proof in at most one case; the number of decoys changes; the final case is the longest.

**Step cases (`steps`, type `elim`)** are played as an investigation instead of a story list. The plan behind them is in [docs/IMPROVEMENTS.md](../docs/IMPROVEMENTS.md).
1. 📞 **call:** the phone rings and a client (`client`, `call`) asks for help. With `film`, a security camera follows: the child taps through its frames (`[emoji, caption, 'blur']`), one caption at a time, no timer; the blurry frame shows *something small*, so the child suspects before proving it (Columbo-style). »Na kraj dogodka« sits in the camera's bar on the last frame.
2. 🔍 **scene:** every sentence hides behind an object (`obj`, `label`); the child opens them all into the pocket 👝. A `dark: true` object needs the 🔦 torch.
   Or 🗣️ **ask** (questioning): every sentence is an answer, with `who` says it and `ask`, the question. It looks like a messaging app: the child taps a face, then a question chip; the question goes out as the detective's bubble, the suspect "types" (…), and the answer arrives. Every suspect has to answer everything. A suspect's own claim (»Vso noč sem bil na polnilcu.«) doesn't cross them off; the hint says »To trdi o sebi. Ali je res?«.
   Or 🔤 **words** (a word search, before the scene): `words: { note, grid, find: [[emoji, WORD]], h1 }`. The child taps the first letter, then the last (either end first); a found word turns green and is crossed off the list, and the words name the places to search in the scene. Only → and ↓, capitals, Č/Š/Ž one cell. Wrong tries: a gentle note → `h1` (2nd) → the row or column of the next word lights up (4th) → its first and last letter pulse (6th). Logged as `puzzle_word`, `puzzle_hint`, `puzzle_done`. Steps run in the order of `steps` (e.g. `['call', 'words', 'scene', 'solve']`); ← goes one step back. The checker tests the grid: Slovenian capitals only, every word exactly once, and no rude word by chance in any row or column. Or 🔐 **lock** (a code lock): `lock: { note, code, h1, h2 }`. The child turns 3–5 wheels ▲▼ and presses »Odpri«; nothing is checked while the wheels turn, so trying every code is dull. Wrong tries: a gentle note → `h1`, where the code is (2nd) → `h2` says the code (4th), so a child who skipped the earlier case is never stuck. It clicks open, and the button to the next step appears. Logged as `puzzle_lock`, `puzzle_hint`, `puzzle_done`. Or 🕐 **order** (a timeline): `order: { note, cards: [[emoji, text]], h1, h2, done }`, cards in the right order (3–5, each starting with a different word: *Najprej, Potem, Nato, Na koncu*). They show mixed; the child taps a card into the next slot (tap it again to take it back) and presses »Preveri«. The right ones stay green, the others go back. Wrong checks: a gentle note → `h1` (2nd) → `h2` (3rd) → the next card pulses (4th). Logged as `puzzle_order`, `puzzle_hint`, `puzzle_done`. Or ✉️ **cipher** (a coded note): `cipher: { note, key: { symbol: 'LETTER' }, gives, h1, missing?, h2?, extra? }`. The message is the sentence `gives`, in capitals; each cell shows its symbol over an empty slot. The child taps a cell (the ring) and a letter tile; a right letter fills every cell with that symbol. `missing` shows one pair as »?«, so the word gives the letter away; `extra` adds up to 2 decoy tiles. Wrong taps: a note → `h1` (2nd) → the symbol lights up in the key (4th) → the tile pulses (6th); at the missing symbol `h1`, then `h2` (says the letter), then the tile pulses. Logged as `puzzle_cipher`. Or 📜 **torn** (a torn note): `torn: { note, parts, gives, h1, h2 }`, 3–4 strips that make the sentence `gives`, in a line; it works like the timeline (»Preveri«, the right ones stay), the strips aren't read aloud. Logged as `puzzle_torn`. A word search can also have a **geslo** (`words.geslo`): when every word is found, the letters left over glow and spell that sentence. **A puzzle gives a sentence:** the sentence a puzzle gives has `from: '<step>'` (and no `obj` or `ask`); it lands in the pocket when the puzzle is solved and is an ordinary sentence in `lie` and `solve`. More puzzle types are planned in [docs/PUZZLES.md](../docs/PUZZLES.md).
   Then, optionally, ❗ **lie** (UGOVOR, right before `solve`): `lie: { claims, claim, breaks, truth, hmm?, about?, h1? }`. 1–3 sentences (quotes with `who`) show as 💬 claims, the other sentences below. The child taps a claim, then the sentence that shows it isn't true (`breaks`: sets of 1 or 2 sentences; a pair needs both). The red stamp slams down, the liar blushes 😳 and "types", and the `truth` (a sentence with `from: 'lie'`) arrives into the pocket. The very first time per detective the owl coaches the two taps and a big red »UGOVOR! ❗« button asks the child to shout it out loud (`dp_ugovor_v1`). Wrong tries: »Oba sta lahko res.« → `h1` (2nd) → the breaker lights up (3rd) → claim and breaker pulse (4th). `hmm` lists near misses [claim, sentence, note] that aren't counted. The liar can be innocent: in `solve` the broken claim is tagged UGOVOR!, and blaming an innocent liar says »Kdor ne pove resnice, ni nujno kriv.« A truth may cross off its own speaker (`clears`) when a breaker names them. Logged as `lie_try`, `lie_hint`, `lie_assisted`, `lie_shout`, `lie_done`; the debrief has an »Ugovor« column. A step case may also have **two proofs**: one names the culprit, the other names nobody; the first with the culprit's face says »Eden je pravi!« and stays green.
3. ❌ **solve:** the child taps a sentence, then a face. An alibi (`role: 'clear'`, `clears: 'robi'`) crosses that suspect off; the proof plus the culprit solves the case. Hints come after wrong pairs: »ne dokaže« → `h1` → the next sentence lights up → the sentence and the face pulse.

On the solved screen: a newspaper (`paper` of the file) with »… je ujela Tima!« (`caught`), the culprit's excuse (`excuse`), and a rank-up. Ranks are 🔰 Vajenec (0 solved) → 🕵️ Detektiv (3) → ⭐ Višji detektiv (6) → 🎖️ Inšpektor (10) → 👑 Glavni inšpektor (15); they show on the ID card and are never lost. The client's thank-you `letter` arrives on the next visit (a later session). The checker tests step cases too: every innocent suspect has exactly one alibi that names them, the culprit has none, there is at most one dark object, and the corkboard card names no suspect.

A **season** (`season: true` in `FILES`) is one adventure with one big mystery (`mystery`). Its cases open one by one (the story goes in order): each opens when the one before it is solved, and a tap on a locked one says which case opens it. A case already solved never locks again. In other adventures only the final waits for the rest. Every case pins a `card` to the 📌 corkboard on the board, and `soon` shows the cases still to come. The first one is 👾 Skrivnost v zračniku, cases 1–6. While a season is still being written (`soon`), the board says the next case is coming. After a solved case the new card flies onto the corkboard, the red string draws, and the detective thinks out loud (`card.think`). From 2 cards on, eyes 👀 blink in a vent on the corkboard (tap: »pip-pip!«; `peek` in `FILES`). `pages: true` draws the cards as typed pages. After `guess.after` cases the corkboard asks »Kaj misliš, kdo je v zračniku?« with 3 choices (`guess` in `FILES`); the child's guess is kept per detective (`dp_guess_v1`). With `guess.again`, after that case the corkboard asks `q2` (»Ali še vedno tako misliš?«) once: »👍 Da« or »🔄 Spremenim«, and the final says whether changing was right. The final case (`final: true`) unmasks the mystery guest: a suspect shown as 👀 »???« (a character with `real`, named in the sentences by where it hides) turns into 👾 Bip on the solved screen, and `answer` in `FILES` says what was in the vent and whether the child's guess was right, there and on the corkboard. With `book` (`{ q, title, by }`), »Naprej« on the final's solved screen goes to the author's question and, on »Da!«, a book cover with the child's ID picture and name (from the ID card, on the device only). Puzzle ideas for a future adventure: [docs/PUZZLES.md](../docs/PUZZLES.md).

Cases are grouped in **adventures** (`FILES`, *pustolovščine*): 🚀 Vesoljska postaja and 🐄 Pri babici na kmetiji, 6 cases each at level A, one per ladder step plus a twist; the 6th is a final case that opens when the others are solved. The original 14 forest cases were removed (they are in the git history). Ideas for the next adventures are in [docs/CASE_FILES.md](../docs/CASE_FILES.md).

**Adventures screen order** (`fileOrder()`, from the saves, so nothing moves unless the child did something): one big hero card with »▶ Nadaljuj« (the adventure played last that still has an open case) or »▶ Začni« (the first adventure for a new detective, otherwise the newest unstarted one); then started, unstarted (tag »NOVO«, no 0/N count) and waiting adventures; seasons carry »🔎 skrivnost«. Finished adventures become tiles on the »🏅 Moje medalje« shelf (tap = play again); a medal earned since the screen was last shown flies onto it.

**Coming soon and release dates.** Under »📅 Kmalu nove pustolovščine« the start screen shows teaser cards: icon, title, a one-line `teaser` question and a countdown (»⏳ Še 7 dni«, »Jutri!«, or »Kmalu« without a date). A tap only wiggles the card. Adventures announced but not written yet are listed in `COMING`. A written adventure goes in `FILES` with `teaser` and `opens: 'YYYY-MM-DD'`: until that day (the device's own date) it stays a teaser and its cases are out of the game; on that day it appears by itself, with no new deploy. Push a dated season before its day. `node tools/cases.mjs` checks every file, dated or not.

**Audio only on request:** nothing is read aloud by itself. Tapping a sentence that is there to read (a story row, a clue in the pocket, an answer in the chat, the call, a puzzle note, the book question) reads it; picking a sentence or a claim, opening a scene object, placing a timeline card and a near-miss note stay silent, so the child reads first. Short instructions (»Najprej tapni stavek, potem obraz.«, »Tu je pretemno …«) and the UGOVOR shout are still spoken.

**»Najprej navodilo« (step cases):** children skipped the instruction on top and went straight to the text, so every step (`BRIEF`: scene, ask, words, lock, order, cipher, torn, lie, solve) now opens with a card: the step's icon and name, a puzzle's own note (`words.note`, `lock.note`, …), then what to do (`UI_AUDIO.how…`, 👉), and »Razumem ✓«. The screen behind is dimmed and takes no taps until then; every case shows it again. The instruction on top of the step has a blue ? and opens the card again. A message during a step (`r.note`: a wrong try, »Najprej tapni …«, a UGOVOR near miss) comes as a card at the bottom with »V redu«; a tap beside it wiggles it. After UGOVOR the truth comes on its own card (»Luka pove resnico:«), and »Vem, kdo je bil!« opens after »Razumem«. Logged as `brief_show`, `brief_ok` (`step`, `ms`; the truth card is step `truth`) and `brief_reopen`; the debrief's »Navodila hitro« column counts cards closed in under 3 s (not read) out of all. When the instruction changes because the child is done (»Vse je preiskano«, »Vsi so odgovorili«, »Ostal je samo eden. Pokaži dokaz!«) it comes as a green card too. In solve, a sentence that crossed someone off is struck through (`r.used`). On the solved screen the culprit's excuse comes on its own card after the stamp (»Luka pravi:«; logged as `brief_ok` step `excuse`), in every case with an `excuse`. Upright phones keep at least 32 px on top (`--safe-top`): in the Safari browser the inset is 0, but the status bar's blur still reaches into the page.

**First launch (board mode):** the child makes a detective ID card (avatar = detektiv / detektivka, sidekick, optional name; stored on the device only, the name is never logged), plays the 🎓 practice case, then picks a file. In the practice case Babica the owl 🦉 coaches: the rest of the screen dims, a thick yellow ring breathes around what to tap and a finger 👆 bounces at it (a group, like the animals, gets the ring but no finger, so it doesn't point at one answer). **Several children on one device:** 👥 on the adventures screen opens »Kdo igra?«, one card per detective (picture, name, rank, solved cases) plus »Nov detektiv«. Each detective has their own ID card, ticks, practice, letters, corkboard and anonymous player id. With two or more detectives, »Igraj!« starts with »Kdo igra?«. The active detective's data stays in the usual keys; the others wait as copies in `dp_detectives_v1` and swap in when picked. Save version 4 makes an existing child the first detective without changing their data. Adult "Nov otrok" in setup clears the card, the ticks and the practice of the detective who played last; the other detectives stay.

## Record audio
1. `node tools/cases.mjs clips > docs/clips.tsv` gives every line as `clipId<TAB>text`.
2. A native speaker records each line, saved as `audio/<clipId>.m4a` (mono, ~32 kbps is plenty). `.mp3` also works.
3. `node tools/build.mjs` writes `dist/index.html` and reports any missing clips.

## Put it on the iPad
1. The repo is published with GitHub Pages; the start page at the root links to this game. For a build with audio inlined, host the contents of `dist/` instead.
2. On the iPad, open the URL in Safari → Share → Add to Home Screen. Open it once from the Home Screen while online.
3. Test in airplane mode: open from the Home Screen, play the sound check.

## Running a session
1. Setup screen: choose the age group (sets level A or B), tick "Pilotna seja" for the pilot child, choose the case order, play the sound check, press "Začni sejo".
   - **🗂️ Otrok izbira na tabli** (default): after "Začni" the child picks an adventure and sees its board (sticker, question and difficulty 🔍 … 🔍🔍🔍🔍🔍), then picks a case. Solved cases get a ✔ that stays on this iPad; one unsolved easy case glows as a suggestion. Solved cases can be replayed. "Dovolj za danes" ends the session. "Počisti kljukice" in setup clears the board for a new child (the logs stay).
   - **Po vrsti**: every case of every adventure in order, from a chosen case, with "Še en primer?" after each case. Use this from 🚀 1 for a comparable playtest. The themed cases exist at level A only, so level B plays them too.
2. Hand the iPad to the child.
3. Adult access during or after play: hold the top-left corner for 3 seconds, then answer the sum.
4. In "Pregled": per-child table (tap a row for the event timeline), age-group summary against the plan thresholds, **Izvozi JSON** after every session, "Nova seja" for the next child.

Logs, names and game progress stay in this browser's storage on the device. The only thing sent is Cloudflare Web Analytics on every page: anonymous visit counts (no cookies, no names, no game data). Offline, it simply doesn't count.
