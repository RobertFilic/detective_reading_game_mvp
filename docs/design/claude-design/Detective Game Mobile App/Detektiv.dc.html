1aProblems for a 7-year-old → design direction
The Cosy Case File
Everything in the game is a paper item on a well-lit desk: case cards pinned to cork, a signed UGOVOR, a newspaper with the child’s name. Screens are never dimmed and nothing turns grey. The sentences are the toy. They’re big, you tap them to hear them, and you choose with a separate magnifier. The owl, Sofija, is the only one who gives hints. Each season is one hue plus one set of emoji, so new seasons don’t need an illustrator.
BIGGEST PROBLEMS
1. Doesn’t read instructions → the rule has to show in the layout and in motion
2. Taps fast → separate targets, 56+ px, 250 ms debounce on choose
3. “Wrong” = failure → only “not yet”, and hints get stronger step by step
4. Lost inside a case → a footprint trail that’s always visible
5. Heard vs chosen looks the same → shown in different ways
6. Dimmed overlay reads as “broken” → no scrim, ever
7. Locked = a grey wall → light kraft-paper backs with just a number
8. Wants to be real → their name signed, stamped and printed
RULES I’M HOLDING TO
Tap the words = 🔊 listen (leaves a dotted line + 👂)
Tap 🔍 = choose (solid fill + ✓ stamp)
Audio plays only when the child taps
No timers, lives, scores or red
Tap targets ≥ 56 px, reading text 26–28 px on iPhone
One accent hue per season, emoji for imagery
One HTML file in the build, fonts embedded offline

JUMP TO
Try this: tap the card with 👣, sign, then on each step tap a sentence to hear it (🔊, then a dotted line + 👂 stays behind). Tap 🔍 to choose. Pick a wrong row three times to see the full hint ladder: owl, then yellow word, then glowing row.

Audio uses the browser’s sl-SI voice if one is installed. Without it, the heard state is simulated.

Use the Tweaks panel to switch the season hue and the player’s name.
