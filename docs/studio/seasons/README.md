# Season pitches

One file per season, `<id>.md`, written by the showrunner and approved by the producer before any case is written. The puzzle designer then adds the puzzles under each case, and the file stays the season's working plan.

A pitch has these parts (see [the showrunner's brief](../../../.claude/agents/showrunner.md)):
1. Title, place, level and reading knobs, the skill rung
2. The big mystery and its true answer
3. The red thread: the card each case pins, the guess and its options
4. Six cases, one line each: question, culprit, motive, proof, decoy, steps, the skill's moment
5. What is new (mechanic, structure, feeling) and what is deliberately not repeated
6. Cast: returning and new, one trait each
7. Risks
8. **Status:** pitched → approved (date) → written → reviewed → playtested
